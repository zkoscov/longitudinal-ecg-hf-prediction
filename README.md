# Longitudinal ECG Analysis for Heart Failure Prediction

This repository contains the code used to identify and prepare study cohorts from the **MIMIC-IV** and **HEEDB** databases for heart failure prediction using longitudinal ECG biomarkers.

The notebooks define the study cohorts, identify patients with and without subsequent heart failure, and extract the relevant diagnosis and ECG dates required for longitudinal and time-to-event analyses.

## Contents

* **MIMIC_HF_extraction.ipynb** — cohort selection and preparation for longitudinal ECG analysis
* **HEEDB_HF_extraction.ipynb** — cohort selection and preparation for longitudinal ECG analysis
